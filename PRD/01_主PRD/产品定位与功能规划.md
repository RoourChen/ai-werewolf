# 产品定位与功能规划

> 归属：01_主PRD · 仓库 https://github.com/RoourChen/ai-werewolf

## 1. 产品定位（一句话）

**AI狼人杀** 是一款面向 **1 名真人 + 6 名不同人格 AI** 的 7 人狼人杀引擎：确定性裁判状态机 +
可解释 Copilot + 三通道怀疑评分与决策轨迹，支持离线 AI 自博弈、真人对战与终局回放。

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 真人玩家 | 入座一个席位，其余 6 席为不同人格 AI；Copilot 实时给出狼人概率、理由与投票建议 |
| 模型评测者 | 批量自博弈，产出阵营胜率、角色存活、Agent 胜率与 Copilot Brier 校准 |
| 开发者 | Python API / CLI 复用裁判、Agent、回放与战绩模块 |

## 3. 核心功能（八大差异点）

1. **房间与匹配**：`Room` 生命周期（OPEN→READY→PLAYING→FINISHED）+ `Matchmaker` 队列成房。
2. **真人席位**：真人经 `Channel` 传输接入，其余席位由 AI 补齐。
3. **AI 玩家配置**：`AIConfig(policy/model/provider)` 决定 6 个 AI 的构建。
4. **实时文字/语音讨论**：讨论阶段 `text`/`voice` 消息广播到全员与观战者。
5. **裁判状态机**：`SETUP→NIGHT→DAWN→DISCUSSION→VOTING→RESOLUTION→FINISHED`，非法迁移拒绝。
6. **观战回放**：事件流 + 聊天 + 决策轨迹保存为 `ai-werewolf.replay/v1` 并回放。
7. **战绩体系**：`StatsLedger` 胜率、角色数据、排行榜与成就徽章。
8. **管理后台**：`AdminBackend` 房间列表、踢人、关房、服务器统计与 Bot 池。

## 4. 核心规则（MVP 硬约束）

- 仅 7 人局：2 狼人 / 1 预言家 / 1 女巫 / 3 村民；无守卫、猎人；非 7 拒绝。
- 死亡不公开身份，终局统一揭晓。
- 狼人刀人只能选存活非狼人；真人狼：AI 建议 → 真人确认 → 超时确定性兜底。
- 女巫每晚最多一种药；首夜可自救、后续不能自救；不能毒自己或死者。
- 首次平票重投（限并列最高票者），再次平票无人放逐；仅被放逐者有遗言。

## 5. 功能范围与非目标

**本轮范围**：单真人 × 6 AI 垂直闭环（角色/人格/怀疑/轨迹/回放）。

**明确不做**（当前里程碑之外）：多真人混房、ASR 语音、Admin HTTP 化、SQLite 战绩持久化、正式部署与运维。
