# 数据埋点方案

> 归属：04_数据埋点

## 1. 埋点对象

| 对象 | 模块 | 说明 |
|---|---|---|
| `GameEvent` | `domain/events.py` | 对局事件流，带 `kind/day/phase/actor/target/audience/id` |
| `DecisionRecord` | `domain/trace.py` | 每个 AI 每次决策的结构化轨迹（append-only） |
| `ChatMessage` | `server/session.py` | 讨论阶段的实时文字/语音消息 |
| `StatsLedger` | `stats/ledger.py` | 胜率、角色数据、排行榜、成就 |

## 2. 决策轨迹关键字段

- 三通道怀疑：`private_suspicion`（真实）/ `public_suspicion`（公开）/ `strategic_threat`（威胁）。
- `delta`（相对上次 private 的变化）、`key_player`（变化最大对象）。
- `evidence`（引用真实可见事件 ID，如 `E3`）。
- `candidates / decision / confidence / rationale`。
- `deception` + `deception_plan`（对象/公开说法/目的/真实依据/编造事件）。
- `fallback_reason`（重试失败或兜底原因）。

## 3. 埋点时机与约束

- **决策发生时**由编排层（`GameSession._decide`）append-only 保存；终局不重算、不回填。
- 记录为不可变快照（`MappingProxyType`），读取不可改内部引用。
- 死亡玩家不产生新评分，历史评分保留。

## 4. 存储与用途

- 存储：`ai-werewolf.replay/v1` JSON（`replay/recorder.py`）。
- 用途：终局回放（“它当时为什么怀疑/攻击我”）、Copilot Brier 校准、战绩统计、模型评测。
