# 卡点清单与子问题

> 记录当前里程碑（单真人 × 6 AI 垂直闭环）的已知卡点、未完成项与待决子问题。
> 更新于：2026-09-02

## 一、当前卡点

### K1 · 真实模型对局（待用户在本地配置 Key，非阻塞）
- 现状：本环境无 `AIWEREWOLF_API_KEY`，真实模型人工验收标记为“等待用户在本地配置 Key”，不伪造通过。
- 已固化的模型配置：Provider=DeepSeek，Base URL=`https://api.deepseek.com`，Model=`deepseek-v4-flash`，非思考模式，JSON Object 输出，Key 只从 `AIWEREWOLF_API_KEY` 读取（禁止出现在代码/测试/日志/异常/回放/Git）。
- 验收目标：单次 P50 ≤3s / P95 ≤8s；硬超时 20s；最多重试一次；单局成本 ≤1元（>2元视为异常）；完整对局不因超时/格式/网络错误中断，失败走合法兜底并记录失败类型。
- 运行记录必须显示实际 provider 与 model（不显示 Key）。

### K2 · 狼人“怀疑变化”语义 ✅ 已解决
- 现状：新增 `threat_delta` / `threat_key_player` 字段，记录战略威胁相对上次的变化；狼人的怀疑演化现在可在回放中展示。

### K3 · “编造事实但分差 < 0.20”的自动判定 ✅ 已解决（有限）
- 现状：`fabricated_event` 必须引用**可见、携带事实（data 非空）且目标一致**的事件；文本填空不再能绕过。
- 残留：语义级“声称与事件内容相反”的自动核查仍未做（需 LLM/人工复核）。

### K4 · 非 room/session 路径不收集轨迹 ✅ 已解决
- 现状：抽取 `make_traced_decider`，`simulate` 现在也构建持久玩家并 append-only 收集轨迹，`--transcript` 输出含 `traces`。
- `arena` 保持聚合评测（其目标是统计，不逐条输出轨迹）。
