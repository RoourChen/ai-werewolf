## 一、当前卡点

### K1 · 真实模型对局（技术连通通过；稳定性接近目标，待复审）
- 已固化：Provider=DeepSeek，Base URL=`https://api.deepseek.com`，Model=`deepseek-v4-flash`，非思考模式（`thinking={"type":"disabled"}`），JSON Object 输出，Key 只从本地 `.env` 读取（未在输出/日志/回放/测试/Git 中记录）。
- 最小真实请求：200，合法 JSON + usage，P50≈1.5s。
- 完整对局（脚本人类座位 + 6 AI，真实模型）多轮：胜方/天数正常，0 网络重试，无中断；P50≈2.8-3.0s、P95≈3.6-4.1s；单局 `estimated_cost`≈0.03-0.05 元（内部估算，非实际扣费）。
- 定向欺骗场景：狼人面对跳预言家的高威胁真人，输出满足规则的故意欺骗（私下 0.00/公开 0.80/威胁 1.00 + 完整计划）。
- 稳定性修复（证据数组、confidence 钳制、狼人 private 0/1 纠正、P 前缀目标、Prompt 澄清、解析失败重试）：重试率 30.4%→0~17%，兜底率 13%→0~6%，随种子波动；剩余失败主要为模型偶发 `json_parse` 与极少数欺骗协议不一致。
- 目标：重试<10%、兜底<5%，尚未稳定达标（小样本波动），待积累 ≥30 公开节点后按数据判定。

### K2 · 狼人“怀疑变化”语义 ✅ 已解决
- 现状：新增 `threat_delta` / `threat_key_player` 字段，记录战略威胁相对上次的变化；狼人的怀疑演化现在可在回放中展示。

### K3 · “编造事实但分差 < 0.20”的自动判定 ✅ 已解决（有限）
- 现状：`fabricated_event` 必须引用**可见、携带事实（data 非空）且目标一致**的事件；文本填空不再能绕过。
- 残留：语义级“声称与事件内容相反”的自动核查仍未做（需 LLM/人工复核）。

### K4 · 非 room/session 路径不收集轨迹 ✅ 已解决
- 现状：抽取 `make_traced_decider`，`simulate` 现在也构建持久玩家并 append-only 收集轨迹，`--transcript` 输出含 `traces`。
- `arena` 保持聚合评测（其目标是统计，不逐条输出轨迹）。
