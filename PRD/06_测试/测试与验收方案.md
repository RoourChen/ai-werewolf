## 3. 验收清单（本轮）

- A1 非 7 拒绝；A2 角色严格 2狼/1预言家/1女巫/3村民。
- A3 人格与身份独立分配、同 seed 可复现；A4 六人格可辨识差异。
- A5 `AIConfig` 真正创建 6 个 LLMBot；A6 每次发言/技能/投票生成完整轨迹。
- A7 三通道区分；A8 欺骗阈值与重试；A9 未授权信息拒绝。
- A10 真人加入到终局揭晓；A11 回放能回答“为什么怀疑/攻击真人”；A12 不回归。

## 4. 真实模型验收方案（待用户在本地配置 Key）

```bash
export AIWEREWOLF_PROVIDER=deepseek
export AIWEREWOLF_API_KEY=...      # 只从环境变量读取，绝不粘贴给任何人
ai-werewolf play --provider env --model deepseek-v4-flash
```

两项验收（取消“每局必须至少一次欺骗”）：
1. **真实模型完整对局**：验证真实 API、人格提示、合法动作、轨迹保存、超时兜底、终局回放。
2. **真实模型定向欺骗场景**：构造“狼人面对高威胁真人”的固定局面，验证模型能输出一次满足规则的故意欺骗。

阈值校准（不因单局结果调参）：先累计 ≥30 个有效公开决策节点，统计未标记但分差超阈值比例、错误标记欺骗比例、重试比例、重试后兜底比例，并人工阅读回放判断欺骗原因是否可理解；仅当数据表明误判或重试过高时才调阈值，禁止为让演示更容易出现欺骗而降低阈值。
