# 数据与接口契约

> 归属：09_数据与接口

## 1. 传输协议（`transport/`）

- `Channel`：`send(Envelope)` / `recv(timeout)` 双向管道（终端、WebSocket、测试均可实现）。
- `Envelope(kind, payload, sender)`；`kind ∈ {decision, event, chat, result}`。
- `decision` payload：`prompt` + `advice`（Copilot）+ `request`（kind/actor/legal_targets/can_heal/can_poison/suggestions）。
- 实现：`transport/memory.py`（`InMemoryChannel`、`Hub`）。

## 2. 事件 schema（`domain/events.py`）

`GameEvent.to_dict()`：`kind, id, day, phase, text, actor, target, data, audience`
（`audience=None` 表示公开，否则为可见玩家集合）。

## 3. 回放 schema（`replay/recorder.py`）

`ai-werewolf.replay/v1`：

```json
{
  "schema": "ai-werewolf.replay/v1",
  "winner": "...", "days": 3,
  "seats": [{"id":0,"name":"你","role":"witch","faction":"village","alive":true,...}],
  "events": [...],
  "human_seats": [0], "persona_map": {...}, "chat": [...],
  "traces": {"1": [{...DecisionRecord...}]}
}
```

## 4. 决策记录 schema（`domain/trace.py`）

`DecisionRecord.to_dict()`：`day/phase/actor/persona/role/kind` +
`private_suspicion/public_suspicion/strategic_threat`（三通道）+
`delta/key_player/evidence/candidates/decision/confidence/rationale` +
`deception/deception_plan/fallback_reason`。

## 5. CLI 接口（`cli.py`）

`simulate`（AI 自博弈）、`play`（1 真人 + 6 AI）、`arena`（批量评测）、
`calibrate`（Copilot Brier 校准）、`replay`（回放）。

## 6. Python API

顶层 `ai_werewolf` 导出：`Referee`、`GameConfig`、`build_roster`、`Persona/PERSONAS`、
`LLMBot/RandomBot/HumanPlayer`、`Room/RoomConfig/AIConfig`、`GameSession`、
`Advice/advise`、`record_session/replay_text`、`StatsLedger` 等。
