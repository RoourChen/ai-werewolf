# UX 验收材料：本地启动、任务清单、问卷、已知限制

> 归属：10_交互页面与真人UX验收 · 5 名测试者 · 出声思考 · 全程记录卡点。

## 1. 本地启动命令

```bash
cd ai-werewolf
source .venv/bin/activate

# 方式 A：一行命令
ai-werewolf serve --host 127.0.0.1 --port 8000

# 方式 B：等价 uvicorn
uvicorn ai_werewolf.server.ws:create_ws_app --factory --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000/`。

**模型**：默认读取 `.env`（`AIWEREWOLF_PROVIDER / AIWEREWOLF_API_KEY / AIWEREWOLF_MODEL`），未配置时自动回退到离线 Mock。页面本身不读取、不显示、不记录 Key。

## 2. 统一任务清单（每名测试者相同）

1. 打开页面，点击「**创建房间并入座**」，确认看到「已入座」提示。
2. 点击「**开始游戏**」。
3. 阅读「**你的身份**」和「**阶段**」提示，用自己的话说出：我是谁、现在是什么阶段、我该做什么。
4. 按界面引导完成本轮需要做的操作（夜晚查验/用药/确认刀人、讨论发言、投票、遗言等）。
5. 观察右侧 **Copilot 狼人嫌疑** 面板，判断它对你做决定是否有帮助。
6. 一直玩到「**对局结束**」，查看胜方与身份揭晓。
7. 点击「**查看回放**」，浏览事件时间线。

**观测者记录**：每个任务步骤的完成时间、是否卡住、卡在哪一步、是否求助、对 Copilot 的反应。

## 3. 结束问卷（简短，5 题 + 自由文本）

| 题 | 问题（1 完全不同意 – 5 完全同意） |
|---|---|
| Q1 | 我能随时知道「我是谁、现在什么阶段、我该做什么」。 |
| Q2 | 整个对局中，我没有因为界面或流程而卡住、不知道该点哪里。 |
| Q3 | Copilot 的「狼人嫌疑 + 投票建议」对我做决定有帮助。 |
| Q4 | 结束一局后，我愿意再玩下一局。 |
| Q5 | 终局身份揭晓和回放让我看懂了这一局发生了什么。 |

自由文本：最卡的环节？最困惑的地方？对 Copilot 的建议？还想要什么？

**验收口径**：看得懂 Q1≥4（≥4/5 人）；不卡住 Q2≥4（≥4/5 人）且无人中途中止；Copilot 有用 Q3≥4（≥4/5 人，含「有帮助但不够」）。Q4/Q5 作为体验参考，不设硬门槛。

## 4. 已知限制（测试前需知会测试者）

- **刷新页面会丢失本局**：前端暂不持久化 `session_token`，刷新后无法自动回到原局，需重新建房开一局。
- **无自由聊天**：讨论阶段只有按轮的「发言」操作，不能随时插话。
- **无语音 / 无多真人 / 无账号**：单机单真人，其余 6 席为 AI。
- **狼人胜率偏强**：离线基线约 89%（llm）/ 74%（random）。这是已知的结构性平衡问题，本里程碑**不改规则**，若测试者抱怨「狼太强」，只记录为平衡信号。
- **Copilot 是规则启发式（非模型）**，只输出「嫌疑概率 + 投票建议」，仅供参考。
- **讨论仅一轮**，发言顺序为座位顺序（当前默认非竞价模式）。
