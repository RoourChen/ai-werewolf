## 1. 本地启动与故障排查

### 启动

```bash
cd "/Users/wq/Desktop/Idear/狼人杀/ai-werewolf"
source .venv/bin/activate
pip install -e ".[server]"    # 首次需装 fastapi/uvicorn/websockets
ai-werewolf serve --host 127.0.0.1 --port 8123
```

浏览器打开 `http://127.0.0.1:8123/`。默认读 `.env`；未配置 Key 时自动回退到离线 Mock（AI 行为确定、不涉 Key），**验收用离线 Mock 即可**。

> 注意：**不要用 8000 端口**（本机被其它项目占用）。

### 故障排查

| 现象 | 排查 |
|---|---|
| 页面打不开 | 确认 uvicorn 已启动、端口未被占用；换端口 `ai-werewolf serve --port 8123` |
| 点「创建房间并入座」无反应 | 看页面顶部「连接」状态；刷新重试；看终端是否有报错 |
| 一直「正在恢复对局…」 | 旧会话残留 → 点「退出本局」，或清空该站点 `sessionStorage` |
| 提交后报错 | 记录页面日志里的错误码；多为目标非法/阶段不符，刷新重连即可 |
| 卡在「等待其他玩家」 | 正常（AI 在决策）；超 60 秒无变化再看终端异常 |
| 刷新后回不到原局 | 房间已删除/过期会回建房页；同标签页刷新才保留会话 |

## 2. 主持人说明词（逐字，禁止提前解释界面）

> 「接下来请你玩一局狼人杀。你是唯一真人，其余 6 个座位是电脑。请用你自己的方式把这局玩完，从打开页面开始，一直到看到对局结果。
> 过程中请随时把你在想什么说出来。我会在旁边记录，但不会提示你怎么操作。
> 如果实在进行不下去，你可以问我，我会把你求助了这件事记下来。」

**主持人守则**：
- 不解释任何按钮/界面的含义，不提示下一步该点哪里。
- 不解释 Copilot 的「正确答案」，不评价测试者的决策。
- 不因个别反馈当场改产品；先跑完 5 人，再汇总共性问题。
- 只记录，不教学；「帮助后完成」**不算独立完成**。

## 3. 统一任务清单（5 名测试者相同）

1. 打开页面。
2. 进入一局：创建房间并入座，开始游戏。
3. 大声说出：我是谁、现在是什么阶段、下一步我该做什么。
4. 独立完成这一局的所有操作，直到看到「对局结束」。
5. （可选）点击「查看回放」浏览一局经过。
